# SISR-MMTE

Système d'Inscription et de Suivi des Requêtes MMTE — Bénin Control SA.

Application web interne de saisie et de suivi des requêtes : saisie, requêtes en cours, tableau de bord hebdomadaire, exports Excel et PDF.
L'accès est réservé aux comptes créés par l'administrateur. Aucune donnée n'est stockée dans ce dépôt.

## Contenu

- `index.html` : l'application
- `config.js` : adresse du projet Supabase et clé publique (à renseigner une seule fois)
- `vendor/` : bibliothèques tierces embarquées (Supabase JS 2.117.1 — MIT, SheetJS 0.18.5 — Apache-2.0, jsPDF 2.5.1 — MIT, jsPDF-AutoTable 3.5.31 — MIT)

## Mise à jour de l'application

Remplacer `index.html` (ou les fichiers concernés) dans ce dépôt : GitHub Pages republie automatiquement en 1 à 3 minutes.
